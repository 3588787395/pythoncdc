## Context
当前Python字节码反编译依赖手工规则，部分结构无法自动分析，导致CFG还原不完备。区域归约是结构化反编译的数学基础，可实现自动化结构识别和归约，提高准确率。

## Goals / Non-Goals

**Goals:**
- 各区域自动识别与归约，提升CFG还原完整性
- 统一区域反编译主流程，支持批量pyc归约测试
- 保证区域归约算法具有可复用性

**Non-Goals:**
- 不涉及Python语法扩展，仅处理基础字节码还原
- 不覆盖特殊平台或三方库专属pyc文件

## Decisions
- 采用区域模式自动检测CFG分解点，基于DominantAnalyzer分析每一区域
- 区域归约算法设计为可插件化，支持扩展
- 测试用例采用站内pyc批量验证，自动生成源文件及标记

## Risks / Trade-offs
[算法复杂度] → 控制区域归约步骤数，优先处理常见结构
[兼容性风险] → 全量测试比对主流程，异常pyc个案单独追踪
[可维护性] → 注释归约规则全过程，方便协作迭代

## Migration Plan
分阶段实现，先支持典型CFG区域，逐步增加复杂结构。每阶段均生成可比拟源文件，便于回滚。
