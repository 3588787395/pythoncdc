## 3. 取证 — the two exits, the shared tail, and the `compile()` shape table

### 3.1 The original, read from the pyc (offsets resolved through `dis`)

`query_trade_strategy_info` (`marshal` of the pyc, `dis.get_instructions`):

```
@196 POP_JUMP_FORWARD_IF_FALSE  argval=614   ← the function-level if's FALSE edge → F
@360 FOR_ITER                    argval=478   ← loop body exhausted falls to @478
@478 JUMP_FORWARD                argval=618   ← EXIT 1 (loop exit) → T
@604 JUMP_FORWARD                argval=618   ← EXIT 2 (try/except exit) → T
@614 LOAD_CONST None / @616 RETURN_VALUE      ← F, the if-false sink ONLY
@618 LOAD_CONST None / @620 RETURN_VALUE      ← T, the function's TERMINAL block, 2 in-edges
```

`query_strategy_id` is the same shape (`@634 JUMP_FORWARD → @648`, else-sink `@644`).

So the original is not "a function that returns None twice": it is a function whose **terminal block
T is a jump target reached by ≥2 exit edges** while the if's false edge lands on a **different**
None-return block F. The instruction multiset is otherwise identical to the product (`delta=0`),
which is why only the *block ownership* can fix it.

### 3.2 The `compile()` table that decides the shape (3.11.7, instructions + resolved targets)

Minimal sources (`log/shape_ablation_r48b.txt`), all `compile()`d and disassembled — not argued:

| source shape | false-edge target | arm exit | None-return blocks |
|---|---|---|---|
| `if c: g()` (no else) | `@30` (T) | **fall-through into inlined** `LOAD_CONST@26/RETURN@28` | 2 (one inline, one tail) |
| `if c: g() / else: return None` | `@30` (T) | **fall-through into inlined** pair | 2 (same bytes as no-else) |
| `if c: g() / return None` (trail only) | `@30` | fall-through | **1** |
| `if c: g() / else: return None / return None` | `@28` = **F, a distinct block** | **`@26 JUMP_FORWARD → @32` = T** | 2, both jump targets |
| loop+try two exits, else+trail (S5) | false edge → else block | `@28 JUMP_FORWARD → @82` and `@72 JUMP_FORWARD → @82` | `@82` (T, 2 in-edges) + `@86` |

`else: return None` **alone** and `no else` compile to byte-identical code, and in both the arm exit
gets its own inline tail copy — that is exactly the shipped defect and it re-confirms the ticket's
pre-falsified list. Only the *pair* (`else: return None` **+** trailing `return None`) makes CPython
keep F and T as two separate blocks and route every exit edge to the single shared T. That is
CPython's implicit-function-tail reuse, and it **is** expressible in the emitted AST — so the
FALSIFIED escape ("the AST cannot express two exits joining one tail") is not needed.

## 4. Criterion as implemented (`core/cfg/region_ast_generator.py`, 2 additive hunks)

**Hunk A — the judge, `RegionASTGenerator._r2121_shared_tail_sinks(region)`** (inserted before base
line 3236 `_is_region_internal_exit_sink`; 105 lines incl. docstring). Returns `(F, T)` or
`(None, None)`, reads no names/offsets/thresholds, mutates nothing. All four gates are same-level
facts from the whitelist (block-tail opcode, predecessor/successor sets, exception edges, the
region's own structure fields):

* **G1** `region` is an `IF_THEN IfRegion` in the **function-body scope** (`parent is None`) with
  `else_blocks`, `elif_conditions`, `elif_final_else`, `merge_block` all empty — regions that already
  have else content or a merge stay on the existing arm / R15-N5 post-if paths, so no double claim.
* **G2** the condition block ends in a **forward IF_FALSE** jump whose target F lies after the
  condition block and is **not** in the region's block set (the false edge is *jumped to* a sink,
  not fallen into the arm).
* **G3** F is terminal (no normal successors), is not an exception-handler entry, is reached by no
  exception edge from the condition block, strips to exactly `LOAD_CONST None + RETURN_VALUE`
  (via the existing `_is_implicit_return_block`), and its **only predecessor is the condition block**
  — so F is this `if`'s else-arm and not somebody else's join point.
* **G4** T = the block with the greatest `start_offset` in this code object (the function's terminal
  block), T is not F, T is terminal, pure None-return, and satisfies the existing
  `_is_return_none_join_block` (≥2 predecessors, or a predecessor arriving by an exact unconditional
  forward jump). Whether T belongs to the region's block set is deliberately **not** required: the
  analyzer records arm-falls-into-function-tail exits in `then_blocks`, which is precisely this
  shape's normal state (victim `@618`).

Reuse, not duplication: `_is_implicit_return_block` (base line 19029) and `_is_return_none_join_block`
(base line 3157) are the same helpers the rest of the generator uses; `get_block_by_offset` is the CFG's
own. Nesting is irrelevant — the judge fires on the function-body IfRegion and F/T identity is decided
by block facts, independent of any try/with/loop depth inside the arm; nested functions get their own
graph and their own instance, same rule.

**Hunk B — the emission, one consumer at the tail of `_if_generate_normal`** (inserted before base
line 22531 `return if_result`; verified: next `def` after the site is `_try_build_await_condition`,
so the site is the function's exit path). On a hit it sets `_r2121_node['orelse'] = [Return None]`
(F) and appends the trailing `return None` (T) as a **sibling statement** after the `If`, i.e.
exactly the two source shapes of §3.2's last row. Statement bodies still come from the single funnel
`_generate_block_statements`; `_explicit_return` (R57-C/R15-10 channel) is stamped so
`code_generator._filter_trailing_return_none` does not eat the new tail. One emitter per block
(principle 2): T's `generated`/`generated_offsets` marks are withdrawn before emission and re-registered
after, as R15-N5 already does for `merge_block`.

Guard closure (C3): only when `if_result` is (or ends with) an `If` node, its `orelse` is empty, no
`_is_elif`/`_is_nested_if` marker is present, and no other region has already claimed T; if any
premise fails the code restores the exact entry state of the two mark sets and returns byte-identical
behaviour to the shipped one.
