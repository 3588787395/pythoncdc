## 2. 判据（全部是结构事实；不读函数名、常量、绝对偏移、指令数阈值）

`_r2143_last_arms_converge_on_continue(region)`（`region_ast_generator.py:15668`，用在 `:16595` 的 orelse 挂载点）：

- ① 当前 `IfRegion` 处在循环里且能取到 `header`（`_current_loop.header_block`）。
- ② `elif_conditions`、`elif_bodies` 各恰为一个（被折叠的节点正好是「最后一个 elif 臂 + 链尾 else 臂」两级；多 elif 链的根节点不是这两臂，故**故意不烩**）。
- ③ 两个臂块序列的**正常出口块**存在且相同（`_r2143_arm_exit_target`：末块无条件前跳 ⇒ 目标块；末块非跳转直落 ⇒ 唯一的、起始偏移更大且不以 `PUSH_EXC_INFO`/`WITH_EXCEPT_START` 开头的后继；其它形态返回 None）。
- ④ 该出口块 T **不是**本链 `merge_block`、不在本链 blocks 内、不是循环声明的 `back_edge_block`/`back_edge_blocks`（那是循环体自然尾，不是源码 continue），且尚未发射（原则 2 每块唯一归属）。
- ⑤ T 是**纯 continue 块**（`_r2143_block_is_pure_continue`：去掉噪声与 `EXTENDED_ARG` 后剩且仅剩一条指令，且它是回跳；落点 = header 本身，或 header 的「纯噪声单后继前驱块」= CPython 3.11 放在 header 前的 NOP 再入块 —— 该谓词与分析端已落地的 [R21-40] 逐字相同，不是新造）。
- ⑥ T 的前驱（除自身外）≥2 且**全部**属于这两个臂，每个臂至少贡献一个。

为什么 ③+④ 就是「必须嵌套」的证明而非偏好：flat 布局下这两臂的出口**必然等于**链的 `merge_block`（这里是 `@1826`，A 臂出口实测跳它）；CFG 实测两臂出口是 `@1822`，而 `@1822` 是一条 continue 的实体块，只有「嵌套 if 自己的汇合点 + 其后同级 continue」才产生这个布局。

归约动作（`:16595`，与已落地 `_ft3_elif_shared` 同一惯用写法）：摘掉 `_is_elif`、标 `_is_nested_if`（发射器走 `code_generator._generate_elif_or_else` 的「嵌套 if ≠ elif」分支，把整个 orelse 列表作为 else 子句依次发射），在 orelse 末尾按序补 `{'type':'Continue'}`，并把 T 记入 `generated_blocks`/`generated_offsets`，否则它会被父序列当成链后/try 后的兄弟语句重复发射。AST 映射：
`If(test, body, orelse=[If(_is_nested_if), Continue])` ⇒ `if test: … / else: if …: … else: … / continue`。
不改动任何跳转目标；判据不成立时零副作用 ⇒ 产物逐字节不变。
