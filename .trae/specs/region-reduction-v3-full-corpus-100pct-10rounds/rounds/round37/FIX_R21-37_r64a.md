## §1 Criterion + population

The defect is in the **analyzer**, not the generator: `_detect_ternary_pattern` cannot find the
diamond's join because post-dominance is destroyed by the try body's exception edges, so the R47
"no value consumer" guard (`region_analyzer.py` landed `:26052–26055`) refuses the `TernaryRegion`,
the region survives as an `IfRegion`, and the generator emits a statement.

Hunk: `RegionAnalyzer._identify_ternary_regions._detect_ternary_pattern`, inserted immediately after
the landed line `merge_block = self.dom_analyzer.find_nearest_common_post_dominator(…)`
(landed `:25001`). Three conditions, all stack facts — no function names, no literals, no absolute
offsets, no counters, no block-count thresholds:

1. **unique non-handler join.** After dropping successors whose instruction stream contains
   `PUSH_EXC_INFO` / `WITH_EXCEPT_START` / `CHECK_EXC_MATCH` (the same exception-entry idiom already
   used at landed `:5412`), the two arms have exactly one common successor `M`, and `M` is neither
   arm. `M` is the real join; the exception edges only revoked its post-dominance.
2. **the open expression is fully spanned by this region.** Forward-simulating the condition block's
   value stack (`dis.stack_effect`) returns to depth 0 **inside** the block — i.e. the block already
   holds a completed preceding statement and the unclosed expression starts here. When the reset does
   **not** exist (the expression began in an earlier block, as in
   `'…'.format(side=A if c1 else B, oper=C if c2 else D, share=…, hedge=E if c3 else F)`) the site is
   a member of a multi-conditional **statement**; converting one member while its siblings stay
   `IfRegion` is measured to regress (see §5), so the criterion declines.
3. **simulation reliability.** Every opcode's stack effect is obtainable and the depth never dips
   below 0; otherwise behaviour is byte-identical to landed.

Reduction: `merge_block := M` and nothing else. `value_target`, `merge_context`,
`_detect_ternary_context`, chained-compare detection, `[B48]` augassign attach, and the downstream
R39 / R39b value-block purity guards in `_create_ternary_region_from_pattern` all run unchanged.
No new `self` state, no block-ownership edit, no AST emitted or suppressed by the criterion itself.

fire-log instrumented copy (`CENSUS_region_analyzer.py`, sha16 `e2f242bd27756d1a`, which differs
