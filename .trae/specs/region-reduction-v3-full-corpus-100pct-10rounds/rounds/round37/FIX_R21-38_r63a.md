## 1. The criterion (structural), and its measured population

**Criterion.** In the `_r23_or_*` short-circuit branch of `_if_generate_normal`, a leftover member of
`region.else_blocks` is emitted into the **arm it is sequenced inside**, which is decided by
dominance, not by the analyzer's label:

> if the short-circuit then-body entry `_r23_or_then` is on the immediate-dominator chain of the
> leftover block, then every path to that block passes through the then suite ⇒ its statements
> continue the **then** suite; the chain returned by `_if_generate_elif_chain(region)` is the sibling
> arm and must not host the body.

and the leftover set is emitted **as a sequence** in block order (region entry → dispatch the region,
plain member → that block's own statements), so a dispatched region's merge/store block — which no arm
set claims — is not swallowed by the bulk-claim that follows.

Facts read: `block.immediate_dominator` (block-local edge-tree field), `region.else_blocks`
membership, the arm's own `then_stmts`/`else_stmts` lists, the dispatch ledger. **No function names,
no literal offsets, no opcode literals, no counters, no thresholds.** Relative offset *ordering* is
used only inside M1's own pre-existing `sorted(..., key=start_offset)`.

Frame facts measured at the firing site (inert line-trace, §2): `region = IfRegion@7604`,
