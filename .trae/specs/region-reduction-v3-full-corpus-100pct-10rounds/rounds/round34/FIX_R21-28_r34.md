## 4. Why the shipped rule swallowed it

`_is_loop_tail_convergence_block` (P1-3b, "显式 Continue 冗余抑制") suppresses the explicit `Continue`
for a block that (a) ends in `JUMP_BACKWARD` to the current loop header, (b) has ≥2 predecessors, and
(c) has all predecessors inside the loop body. Its own hand-off comment at the call site
(`region_ast_generator.py:26886-26887`) states the assumption that broke:

> `_is_loop_tail_convergence_block`（≥2 前驱汇合）仍保留为二次判据：真显式 continue 块只有 FOR_ITER 单前驱，不会被它误伤。

`ipo_stocks_order @3572` is a real explicit `continue` with **two** predecessors, because the block is the
merge of the nested `if submarket_type in ('4', [])` — its false edge and its then-arm's fall-through both
land on the `continue`. The premise "explicit continue ⇒ single FOR_ITER predecessor" is therefore false,
and the suppression deleted the statement.

## 5. Criterion installed

Three facts, all read from this `LoopRegion`'s own fields and the block's own instructions, deny the
suppression only when none of them holds — i.e. when the recompiled loop cannot regenerate this jump:

```python
_lc_payload = [i for i in block.instructions
               if i.opname not in ('RESUME', 'NOP', 'CACHE', 'EXTENDED_ARG',
                                   'PUSH_NULL', 'POP_TOP', 'JUMP_BACKWARD',
                                   'JUMP_BACKWARD_NO_INTERRUPT', 'JUMP_FORWARD',
                                   'JUMP_ABSOLUTE')]
_lc_declared = getattr(self._current_loop, 'back_edge_block', None)
_lc_declared_set = set(getattr(self._current_loop, 'back_edge_blocks', None) or set())
if _lc_declared is not None:
    _lc_declared_set.add(_lc_declared)
if (not _lc_payload
        and block not in _lc_declared_set
        and block.start_offset != max(_lc_b.start_offset for _lc_b in _lc_body)):
    return False
```

- **no statement payload** — a block that carries work is already emitted for its statements and its
  trailing back-edge is the iteration tail the loop construct re-emits; adding `continue` after it makes
  the statements that follow unreachable (`quote @1818`, measured −14 instructions).
- **not the loop's declared back-edge block** — the region itself names which block holds the natural
  tail (`quote/real_quote check_limit @1324/@1302`, `broker on_before_trading_start @1232` are named;
  the victim is not).
- **not the body's terminal block** — the 479 terminal hits keep today's behaviour untouched.
