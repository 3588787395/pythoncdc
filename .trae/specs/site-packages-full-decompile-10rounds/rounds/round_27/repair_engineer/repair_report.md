# Round 27 — Repair Engineer Report (FINAL STATE)

## Change applied (final)
**EXC-2 only** — a surgical guard in `core/cfg/region_analyzer.py`,
`_identify_try_except_regions` (conditional-jump successor expansion that pulls
if-branch bodies into `try_blocks`).

- The guard excludes only a *pure glue* block: a successor `_succ` whose **sole**
  instruction is an unconditional `JUMP_FORWARD`/`JUMP_BACKWARD`/
  `JUMP_BACKWARD_NO_INTERRUPT`/`JUMP_NO_INTERRUPT` whose only non-exception target
  offset `>= handler_start`. Such a block is the CPython 3.11 "skip-handler"
  hoisted-return glue emitted when a trailing `return` is lifted out of a
  `try/except`. Excluding it stops the AST generator from inlining the post-try
  `return` inside the try body (which diverged at the
  `JUMP_FORWARD/PUSH_EXC_INFO/BUILD_TUPLE/CHECK_EXC_MATCH` boundary, verified on
  `PositionDict.__missing__`).
- Requiring `len(_succ.instructions) == 1` (pure glue) makes the guard surgical: a
  genuine if/else branch body block carries real instructions before its
  terminating jump, so it is never mistaken for hoist glue. This was the key
  refinement — an earlier broader version (exclude any block ending in such a
  jump) wrongly dropped real branch bodies and broke 3 files.
