## 二、getPboxAccount 偏移级差异清单

### 差异 A（新家族 W14-B）：三处分支尾裸 return 被丢弃

orig 在三个错误日志分支末尾各有一组裸返回（每组 LOAD_CONST None; RETURN_VALUE，共 −12 字节）：

| 偏移 | 对应源码位置 |

| 550–552 | 创建臂 `if error_no != 0:` 尾 `return` |

反编译输出全部丢弃该语句；净差 −8 字节（另 +6 字节为补入的 JUMP_FORWARD、−2 为函数尾差异）。

### 差异 B（新家族 W14-A）：if/elif/else 链被扁平化错写

orig 真实结构（已验证，见 §三）为「外层 if/else + 内层 if/elif/else 三臂链」：

```python
def getPboxAccount(username, op_station, account_type, login=False, logout=False):
    pboxAccount = pboxAccounts.get(username, None)
    if pboxAccount is None:
        ...
        if error_no != 0:
            ...日志...
            return                      # 裸 return
        else:
            ...成功日志...
    else:
        op_station = get_pbox_account_op_station(op_station, pboxAccount)
        if not pboxAccount.connect_flag and not logout:
            ...重连...
            if error_no != 0:
                ...日志...; return       # 裸 return
            else:
                ...成功日志...
        elif pboxAccount.op_station != op_station and not logout:
            if login:
                ...reconnect()...
                if error_no != 0:
                    ...日志...; return   # 裸 return
                else:
                    ...成功日志...
            else:
                return 'logout'
        else:

    return pboxAccount                   # 四路汇合的单一共享尾部 return
```

反编译输出错写为：

```python
    if v is None 分支内: ... return pboxAccount     # 共享 return 移入创建臂（W14-C）
    else:
        ...
        if not connect_flag and not logout: ...
        if pboxAccount.op_station != op_station and logout or login:  # 条件错写
            ...reconnect...
        else:
            return 'logout'
        app_log.info('不需要重新建立连接')            # 臂归属错置为链后语句
        # 函数结束：隐式 return None                  # W14-C 另一半
```

错写要点：
1. elif 臂条件 `A and not logout` 被改写进 `A and logout or login`——丢 not、把嵌套 `if login / else: return 'logout'` 折叠进布尔链；
2. 最终 else 臂的"不需要重新建立连接"日志挪到链后；
3. 关键跳转极性证据：orig offset 950 `POP_JUMP_FORWARD_IF_FALSE → 1294` 与 954 `POP_JUMP_FORWARD_IF_TRUE(logout) → 1294` 双双指向尾日志臂，仅 elif 链形态可产生该组合；decomp 的 944/948/952 是标准 `(A∧B)∨C` 布局。两者真值表不同：站点相同且 login=True 时 orig 打尾日志后返回 account，decomp 却执行 reconnect；
4. 共享尾部 `return pboxAccount`（offset 1350，被 612/928/1288 三处 JUMP_FORWARD 及 1348 fallthrough 汇合）被移入创建臂内联 + 函数尾隐式 None。

### 差异 C（低优先级）：模块级三个 NOP 无法再现

orig 模块级 offset 94–98 有三个 NOP（原编译器产物）。反编译器以三条 `while False: pass` 占位，但该语法编译为零指令 → 模块 co_code 118 vs 112 字节。常规源码语法无法产生孤立 NOP，属环境性残差。
