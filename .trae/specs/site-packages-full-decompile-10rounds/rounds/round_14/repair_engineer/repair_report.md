## 三、根因与修复原理（最终判定规则）

**W14-A（链扁平化错写）判定规则**：布尔链合法性由「失败路径汇聚性」唯一决定——
- 链内全部成员的短路跳转目标解析为同一汇合块 ⇒ 单一 and 复合条件（含负极性操作数），统一归一为 'and' 并按跳转方向逐项还原 `not`；
- 真/假出口指向不同汇合块的链 ⇒ 不是扁平布尔链，断链/裁剪/拒绝，交还 IfRegion 层级重建嵌套结构。

**W14-B（裸 return 发射规则）判定规则**：指令背书的显式性由「语句位置」决定——
- RETURN 前紧邻显式 `LOAD_CONST None` 且其块之后仍存在可达非平凡代码（兄弟臂/汇合后续）⇒ 源码显式裸 return，必须发射；
- 函数尾仅跳转边可达的 trivial 返回块（其后无非平凡代码）、孤立 RETURN_VALUE（值来自前驱块跨块压栈）⇒ CPython 对隐式返回做 jump-threading 的产物，禁止作为语句发射；
- except handler 上下文维持 R23-N16 原保护。

**W14-C（共享尾部语句归属）判定规则**：多前驱汇合块（存在收集集外前驱，或为各臂公共支配后继 merge_）不得吸入任一单一分支，归属链外文本位置。
