## 修复点（region_analyzer.py `_collect_branch_blocks`，共 2 处）

### 1. R14b none-tail 豁免收紧（前驱连接性判据）
W14-C 反向剪枝中，以 `LOAD_CONST None + RETURN_VALUE` / `RETURN_CONST None`
结尾的块被无条件豁免剪枝（R14b：防止 try/except 两臂汇入的共享返回尾被
剪除导致臂尾 return 丢失）。但豁免不应适用于**在收集集内已无任何前驱**的
块——它们的唯一前驱（如 amount 链的 888）已因外部性连锁剪除，说明该块
只是经已剪除路径可达的体外块，不是本分支的共享尾。收紧后：none-tail 块
仅当「至少一个前驱仍在当前收集集内」时豁免，否则落入外部前驱剪枝。
合法共享尾（两臂汇入：本臂尾块在集内）不受影响。

### 2. R37 可达性收敛遍（全局结构判定）
前驱外部性是逐块局部判据：循环体块因回边内部互连，桥块（order_market 的
850）剪除后仍整体存活，post-chain 循环被整体吸入前序分支（repro_10）。
剪枝收敛后新增可达性遍：仅保留从 entry 出发、沿正常控制流边（排除
exception_successors，与 R09 一致）、经保留块可达的块。合法分支体必然从
entry 可达，对正常收集零影响；体外组件（循环、后继链的离线 else 体）与
entry 断连被一并移除。仅 merge=None（无界收集）场景适用，有 merge 边界的
收集不受影响。
