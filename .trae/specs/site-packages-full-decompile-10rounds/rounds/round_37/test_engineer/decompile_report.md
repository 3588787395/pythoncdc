## 根因（字节码证据）

原始源码结构（重建）：

```python
if exchange_type == '1':
    ...（部分分支 return）
elif exchange_type == '2':
    if limit_price is None: limit_price = 0
    if market_type not in (0, 2, 3, 4, 5):
        log('市价委托深证股票时市价类型仅支持0、2、3、4、5类型，委托取消')
        return None              # 分支不 return，落穿到链后

    return None                  # 终态
if amount > 0:

```

CFG 事实（dis 实测）：
- amount 链的 else 体 block@932 是**离线布局**：唯一前驱是 elif 条件块 888
  的 `POP_JUMP_FORWARD_IF_FALSE → 932`，体内 `LOAD_CONST None; RETURN_VALUE`
  直接终止，不回到汇合点 976。
- exchange 链因 else 臂终态（return）而 **merge=None**（post-dominator 找不到
  共同汇合点）。

## 缺陷家族 W37：merge=None 无界收集的「体外块吸入」

`_check_elif_chain` 对 '2' 分支体收集调用
`_collect_branch_blocks(entry=738, merge=None, stop={800})`（插桩实测）。BFS
越过链后代码 850（amount 链入口）继续收集 850/862/888/900/932/976/…。
W14-C 反向剪枝以「前驱外部性」逐块移除：850（外部前驱 622）→ 连锁剪除
862/888/900 → 976/1068/1082/1084。**但 932 被 R14b none-tail 豁免保护**
（`LOAD_CONST None; RETURN_VALUE` 结尾），尽管其唯一前驱 888 已被剪除、
它在收集集内已无任何路径——932 以「共享返回尾」名义存活，被吸入 '2'
分支体。生成端据 elif_bodies 原样发射 → `log('股票委托数量为0'); return None`
错挂进 `elif '2'`，amount 链丢失 else。

对照组（repro_03/04/07：值返回 else / 落穿 else / raise else）证明缺陷
特定于 none-tail 终态 else 体；repro_10 证明**循环块**因回边内部互连，
前驱外部性判据无法剪除（桥块 850 剪除后循环仍整体存活被吸入）。
