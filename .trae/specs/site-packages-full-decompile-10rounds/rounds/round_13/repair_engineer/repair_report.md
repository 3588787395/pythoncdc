## 三、最终判定规则（结构判据，无 depth 硬编码/pyc 特判/反模式前缀命名）

1. **A 组正常副本收集**（`_find_finally_normal_copy_blocks`）：锚点来自 try/handler/else 出口的正常边可达集交集（post-dominator 收敛点，K < exc_start、无异常帧标记、非 Loop 入口）。收集序列恰为单块且满足：
   - 块以 RETURN_VALUE/RETURN_CONST 终止；
   - 异常路径副本（finally_blocks）镜像含 RETURN 终止符；
   - 双副本 `_w13_data_stream` 完全一致且非空；
   - 块内 POP_TOP 仅允许紧随 SWAP 且其后即 RETURN 终止符（迭代器弃置对）；
   - 无 PUSH_EXC_INFO/POP_EXCEPT/RERAISE/WITH_EXCEPT_START/CHECK_* 与跳转。
   → 返回 `[K]`，finalbody 以其为唯一语句源派发；异常副本静默登记不发射。
2. **循环体跨块栈传值 return 链**（HBS）：块内 `SWAP n; POP_TOP; RETURN(_CONST)` 且 stmt_instrs 非空 → SWAP 跳过、POP_TOP 经 skip_initial_pop 消费、装载序列归 RETURN 重建单一 Return(expr)。
3. **B 组分类分流**（analyzer）：bare-except 同形帧（PUSH_EXC_INFO 后紧跟 POP_TOP）若异常链全 RETURN 终止且存在前置镜像正常副本 → 'finally'；否则 'except'。
4. **嵌套层数**：handler 入口保护区间起点前连续 try 标记 NOP 游程长度 N>1 ⇒ handlers 下沉 (N−1) 层内层 Try（重编译逐 Try 再生标记 NOP，偏移对齐）。
5. 未命中以上任何判据时，全部维持 R11/R12 既有路径（legacy finalbody、原拒绝分支），对照组（if/else 双 return、finally 无 return）零改动。
