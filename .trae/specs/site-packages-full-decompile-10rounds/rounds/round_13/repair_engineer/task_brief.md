# Round 13 修复任务卡 —— 家族 W13：try/finally 尾部 return 返回值丢失

日期：2026-08-23 ｜ 交付对象：修复工程师 ｜ 目标 pyc：`site-packages/fly/common/inform_info.pyc`

## 一、缺陷摘要

`finally:` 块**直接子级为单条 `return <expr>`** 时（无嵌套控制流包裹），反编译器丢失返回值：

- A 组（表达式返回）：`finally: return value` → 发射 `value`（裸 Expr）+ `return None`，正常/异常两条路径的返回值均被丢弃；
- B 组（常量返回）：`finally: return 42` → 正常副本整体被吞 + 异常副本被误发射为裸 `except:` 子句。

目标文件 `inform_info.get_value` 即 A 组实例：任何路径原语义都返回配置读取结果，现产物恒 `return None`——静默数据丢失。

## 二、根因证据

### 1. 字节码层（marshal 跳 16 头 + dis，见 decompile_report.md 第三节）

`try: v=f() \n finally: return v` 在 CPython 3.11 下 finally 双副本：

```
block@18: LOAD_FAST v; RETURN_VALUE                      # 正常路径副本
block@22: PUSH_EXC_INFO; LOAD_FAST v; SWAP 2; POP_TOP; SWAP 2   # 异常副本前段
block@32: POP_EXCEPT; RETURN_VALUE                       # 异常副本尾段
block@36: COPY 3; POP_EXCEPT; RERAISE 1                  # 清理帧
```

RegionAnalyzer 输出：`TryExceptRegion(entry=8, blocks=[8,18,22,32,36], finally_blocks=[22,36,32], has_finally=True)`；正常路径副本 block@18 游离为独立 Region(entry=18)，无任何子区域引用它。

复现命令：

```powershell
python d:\Temp\opencode\r13_trace.py    # HBS/GBS 插桩：finalbody=[Expr(v), Return(None)]
python d:\Temp\opencode\r13_blocks.py   # 块指令 + 区域划分
```

### 2. AST 层插桩实锤

对 repro_01 的 AST dict：`Try.finalbody = [Expr(Name 'v'), Return(Constant None)]`——Return(v) 被拆成裸表达式 + 伪造 Return(None)。

### 3. 嫌疑方法与线索（core/cfg/region_ast_generator.py）

1. **`_generate_try` finalbody 组装（≈L19397-19581）**：
   - `_w11a_nc_blocks` 为空 → 走 legacy 分支逐块 HBS `region.finally_blocks=[22,36,32]`；
   - **W11-A 正常副本收集 `_find_finally_normal_copy_blocks`（L18174 起）漏收本形态**：单块、以 `LOAD_*;RETURN_VALUE` 结尾、被独立切分的正常路径副本（block@18）未成为候选锚点，导致双副本重组退化为 legacy。
2. **`_generate_handler_body_statements`（L19850 起）**：
   - block@22 过滤 PUSH_EXC_INFO/POP_TOP 后把 `LOAD_FAST v`+SWAP 栈操纵当裸语句 → `Expr(v)`；
   - block@32 只剩 `POP_EXCEPT; RETURN_VALUE`，值在**前驱块栈上（跨块栈传值）**，本地无表达式可重建 → 回退伪造 `Return(None)`。
   - 注意 L19900-19937 已有 as-var cleanup / return-chain 判据（repro_07/quotation 修复），但只覆盖 except handler 场景，未覆盖 finally 异常副本的 `SWAP2/POP_TOP/SWAP2 + 跨块 RETURN_VALUE` 模式。
3. **旁注**：`ast_generator_v2.py:18337 _remove_returns` 有同类「finally 内 return→Expr」降级（非默认管线，建议一并纠正注释与逻辑，防切换管线复发）。

### 4. 修复方向建议（供参考，不限定实现方式）

- 方向一（推荐，延续 W11-A）：扩充 `_find_finally_normal_copy_blocks` 候选判据，纳入「以 LOAD_*/LOAD_CONST + RETURN_VALUE 结尾的单块正常副本」；命中后 finalbody 以正常副本为唯一语句源发射 `Return(<expr>)`，异常副本（含跨块 SWAP2 链）静默登记。
- 方向二：legacy 分支内新增「finally 异常副本 return 链合并重建」——识别前驱块尾 `LOAD_* [+ SWAP 2; POP_TOP; SWAP 2]` 与后继块 `POP_EXCEPT; RETURN_VALUE` 的跨块栈传值，用 ExpressionReconstructor 重建 `Return(<expr>)`；禁止在值缺失时伪造 Return(None)（应回退到正常副本或告警）。
- B 组（const）需同时保证：正常副本不被吞、异常副本不得误判为 bare except handler（检查 handler 判据中 PUSH_EXC_INFO 后紧跟 POP_TOP 无 CHECK_EXC_MATCH 的帧是否来自 finally-return 形态）。
