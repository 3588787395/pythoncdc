# 第3轮精准修复实施方案

## 修复目标
- 基准成功率: 87.50%
- 第1轮成功率: 36.36%
- 第3轮目标: **50%+**（提升13%+）
- 关键指标: validate_data和exception_handling_complex函数的字节码匹配度显著改善

## 核心问题定位
基于前两轮深度分析，确定3个核心问题:

### 问题1: 异常处理器类型分类不精确
- **影响函数**: exception_handling_complex
- **表现**: 183个字节码差异
- **根因**: _classify_handler_type函数对finally/except区分不准确

### 问题2: FOR_ITER循环回边检测错误
- **影响函数**: validate_data 
- **表现**: 155个字节码差异
- **根因**: 循环体边界判定不精确

### 问题3: 跳转目标计算偏移
- **影响范围**: 多个函数
- **表现**: 指令序列错位
- **根因**: 控制流跳转的target计算错误

## 第3轮精准修复策略
采用"小步增量、精准打击"策略，逐个解决核心问题:

### 修复阶段1: 异常处理器分类精度提升
**实施重点**: 增强_classify_handler_type算法
- 改进PUSH_EXC_INFO后续指令分析
- 优化finally块RERAISE识别逻辑  
- 加强cleanup RERAISE模式识别

### 修复阶段2: 循环回边检测优化
**实施重点**: 改进_loop_regions中的循环识别
- 增强FOR_ITER循环的header检测
- 优化回边目标计算
- 改进循环体边界判定

### 修复阶段3: 跳转目标计算修正
**实施重点**: 优化控制流分析
- 改进条件跳转的target计算
- 优化backward jump识别
- 增强跳转链分析

## 实施方法论
严格遵循区域归约算法4大原则:
1. **自底向上归约**: 内层结构优先处理
2. **每块唯一归属**: 避免区域重叠
3. **嵌套即抽象节点**: 子区域抽象化
4. **入口引用语义**: 父区域引用子入口
