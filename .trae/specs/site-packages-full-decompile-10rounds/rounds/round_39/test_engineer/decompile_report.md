## 3. 根因分析（复现驱动）

get_history 修复后已 FULL MATCH，无需对失败做定位；但为构造有效最小复现，用形态探测脚本（`round_39/test_engineer/probe_w40.py`，未修改核心代码）在修复前代码上迭代定位了缺陷触发的充要条件。

**缺陷定位：`region_analyzer` 区域识别层（非 `region_ast_generator`）。**

- 触发字节码形态（get_history，偏移 152–470）：`query_date`/`include` 为**闭包 cell 变量**（`MAKE_CELL` + `STORE_DEREF`，被函数内 dictcomp 捕获）；菱形 true 值块 = `[调用链表达式; STORE_DEREF query_date; LOAD_CONST False; STORE_DEREF include; JUMP_FORWARD]`，条件为 BoolOp 短路链布局。
- 误识别：`_create_ternary_region_from_pattern` 的放松接纳路径（has_jump_forward_skip / 嵌套三元接纳，绕过 `_is_ternary_block` 单表达式校验）把该语句级菱形吞并进三元链——值块中的两条赋值（STORE_DEREF）与 else 体语句全部被丢弃，违反区域归约算法「表达式级区域不得吞并语句级块」原则。
- 探测证据：形态 A–D（STORE_FAST 版本，无闭包）修复前全部 PASS；形态 E（闭包 + and 链）与 F（闭包 + `A and not B or C`）修复前 FAIL（304→148、268→128 字节，条件块腰斩），与 get_history 症状一致——**闭包 cell 变量 + 值块含非 walrus STORE_DEREF 是触发关键**。
- 修复机制：值块纯度守卫检测到值块含非 walrus 的 STORE_*（COPY 1 + STORE 对豁免）即 `return None`，交由 IfRegion 按语句级结构归约——一次正确。
