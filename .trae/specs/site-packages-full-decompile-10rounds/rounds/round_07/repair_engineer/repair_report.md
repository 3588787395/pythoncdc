## 三、根因 B 最终判定规则

**折叠许可判据（算法化，无深度上限、无文件/函数名特判）：**

设候选链 `[c_out, c_in1, ..., c_in_k]`（外层 IfRegion 条件块 + 各嵌套 IfRegion 条件块），模式由既有 `_detect_or_short_circuit()` 决定：

1. **and 链合法 ⇔ 所有操作数的条件跳转目标是同一块。**
   CPython 对扁平 `A and B` 的 lowering 中每个操作数 false 出口指向同一 else/exit；对嵌套 `if A: if B: ... else: E`，外层 false→E、内层 false→then 末尾 JUMP_FORWARD，目标必然不同 ⇒ 拒绝折叠、保持嵌套。
2. **or 链合法 ⇔ 相邻操作数 fall-through 串联（FT(c_i) == c_{i+1}）且非末操作数跳转目标 == 末操作数 fall-through（共享 body 入口）。**
   对应 `if A or B:` 编译形态（首操作数 true 跳共享 body、末操作数反向跳 else）。满足时外层条件取反作首操作数、内层 test 作末操作数、内层 orelse 升为整体 orelse。
3. 配套修正：
   - 条件极性判定排除纯跳转连接块（汇合点/回边不含语句，进入它≠进入 then 体），防止循环内链式比较被取反；
   - 循环回边的显式 Continue 只在块含有效用户指令时补发；嵌套循环的 FOR_ITER 耗尽出口（for_iter_exit）不补发；
   - 链式比较清理型 else 若跳出包围循环则承载真实 `else: break`，须生成分支而非丢弃。
