## 2. T2 根因定位辅助（只分析不改代码）

### 2.1 区域归约产物（CFGRegionAnalyzer.analyze() 返回列表）

关键异常三件套：
1. **BoolOpRegion{B(0), B(122)} 非法折叠**：B(0) 尾部 `POP_JUMP_FORWARD_IF_FALSE → 724`，B(122) 尾部 `POP_JUMP_FORWARD_IF_FALSE → 722`，跳转目标不同（724≠722），按 R07 已验证规则不应折叠；
2. **同一子区域同时挂 children 与顶层列表** → RegionASTGenerator 双重发射（症状 1 的直接来源）；
3. WHILE_LOOP 的 region_blocks 吸收了前置块 B(122)（Step 9 condition_block 反向链前驱收集），预测试块的语句部分无处安放。

### 2.2 代码级证据：折叠校验对二元素链恒真

`core/cfg/region_analyzer.py`，`_detect_boolop_chain_start` / `_detect_while_boolop_forward_chain` 共用的回退校验（~L18524-18545）：

```python
all_ft_consistent = True
for cb, _ in chain[1:]:
    ...
    if len(chain) >= 2 and cb == chain[-1][0]:
        continue                      # ← 链尾块被无条件跳过
    if cb_ft != first_ft:
        all_ft_consistent = False
        break
if all_ft_consistent:
    return chain
```

对本例二元素链 `[B(0), B(122)]`：`chain[1:] == [(B(122), 'and')]` 且其恰为 `chain[-1][0]` → `continue` 跳过唯一待检元素 → `all_ft_consistent` 恒为 True → 非法链放行。`all_same_target` 主校验（L18512-18522）确实拒绝了 724≠722，但回退分支将其推翻。合并点解析 `_boolop_resolve_merge`（L18635 起）随后把 merge 定到循环出口附近，BoolOp 就近挂入 WHILE_LOOP.children。

### 2.3 阶段归属判断

| 候选假设 | 判定 | 依据 |
|---|---|---|
| SequenceRegion 重复归约 | **排除为主因** | 重复对象是"子区域同时出现在 children 与顶层"，非序列归约自身复制块；直接诱因是 BoolOp 吞块后注册路径分叉 |
| LoopRegion 前置块二次吸收 | **次要成立** | WHILE_LOOP.blocks 含前置块 122；但吸收本身不产生重复文本，重复来自注册分叉（§2.1-2） |
| while 复合条件回边误判 | **排除** | 回边 684→332、header=332 识别均正确；错在条件块 122 的归属与折叠 |
| **BoolOp 折叠回退校验漏洞** | **主因** | §2.2 代码证据 + repro 矩阵（仅复合条件 while 失败）完全吻合 |

### 2.4 下游连带（症状 3b）

FOR_LOOP 区域在 analyze() 返回列表中存在且结构正确，但 RegionASTGenerator 未发射（输出止于泄漏的 else 尾块）。疑与前序区域重叠消费/发射中断有关，需修复主因后复测确认是否自愈。
