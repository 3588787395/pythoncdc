## 1. 缺陷摘要

目标 pyc `site-packages/IQData/api/get_block_stocks.pyc` 反编译破损：前导语句重复发射（一份丢元组解包）、外层 if 测试与 while 预测试被误折叠为 and 复合条件、else 尾块泄漏顶层、尾部 for+return 整段缺失。12 个最小复现中 7 个文件 FAIL（函数级 26/35 PASS），**仅"and/or 复合条件的 while"触发**。

## 2. 根因证据链

1. **主因 — BoolOp 折叠回退校验对二元素链恒真**
   位置：`core/cfg/region_analyzer.py`，`_detect_boolop_chain_start` / `_detect_while_boolop_forward_chain` 共用回退校验（约 L18524-18545）：
   ```python
   for cb, _ in chain[1:]:
       if len(chain) >= 2 and cb == chain[-1][0]:
           continue          # 链尾块被无条件跳过 → 二元素链校验空转
       if cb_ft != first_ft:
           all_ft_consistent = False; break
   ```
   本例 B(0) false→724、B(122) false→722 目标不一致；`all_same_target` 主校验正确拒绝后，回退分支因上述 `continue` 恒真放行。修复方向：链尾块不得豁免 fallthrough 一致性检查（或要求各链块跳转目标经 JUMP 归一化后收敛到同一 merge）。
2. **次因 — 子区域双重注册**：区域 dump 显示 `BoolOpRegion{0,122}` 与内层 `IfRegion{332,460,634}` 既挂在 WHILE_LOOP.children 又保留在顶层返回列表 → RegionASTGenerator 双重发射。检查 analyze() 后段子区域挂接/从工作列表摘除的配对逻辑。
3. **连带 A — 外层 If 未成形**：B(0) 被 BoolOp 吞并后 `error_msg['error_no']==0` 的 IF_THEN_ELSE 消失，else 块(724-772)泄漏为顶层尾块。
4. **连带 B — WHILE_LOOP 吸收前置块**：Step 9 condition_block 反向链把预测试块(122)并入 region_blocks；旋转 while（3.11 入口预测试 + 底部闩锁）形态下条件块归属需重新审视。
5. **连带 C — FOR_LOOP 未发射**：analyze() 返回列表含 FOR_LOOP 但生成阶段无输出，疑为重叠消费/发射中断，修主因后复测确认。
