## 3. 判定规则最终描述（本轮沉淀的算法语义）

1. **and/or 链折叠合法性（唯一判据）**：二元素及任意长度链必须逐操作数校验「条件跳转目标收敛到同一出口块」（R07 all_same_target 规则）；任何操作数目标不一致 → 整链不折叠，保持嵌套 IfRegion 归属。不存在任何 len(chain) 旁路或 fallthrough 替代判据。该规则同时约束前向链检测与 while 条件反向回溯两条路径。
2. **纯 sink 分支的合并点解析**：当一分支以 RETURN/RAISE 终态时，merge 取另一分支的 JUMP_FORWARD 目标且无需 sink 可达；直连查找落空时沿后继链搜索跳转桥，但必须满足「跳板位于 sink 分支之前、目标位于其后」的经典跳越布局，且桥与目标归属区域不同。
3. **旋转 while 的闩锁重检归属**：CPython 在回边复制复合条件求值；末次重检与循环体合块（header 尾部 FORWARD→cond_exit + fallthrough 直达 BACKWARD 回边）及独立前置重检块均为隐式条件重求值，不渲染为语句；含 STORE 的闩锁块仍走 recheck_store_stmts 提取路径保留每迭代赋值。
4. **区域唯一归属**：条件上下文 BoolOp 的非平凡 merge、循环结构块（header/back_edge/condition_block）、子循环条件链块均由其唯一归属方发射；try 体/循环体遍历遇到直接子 LoopRegion 的条件链块时优先分发整循环，杜绝表达式片段抢先渲染与语句双份/丢失。
