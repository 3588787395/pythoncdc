## 三、根因方向判定

### 先排除 W07–W14 残留（探针实验，d:\Temp\opencode\r15_probe.py）

- W07 嵌套 if 折叠：A01/A02/A03（嵌套 if-return 与外层共享汇合点、and 链+嵌套 if、双 if 共享汇合）全部 PASS → 非 W07 残留。
- W09 循环吞并 / W10 with 吞并 / W11 finally 重排 / W12 except 截断：本函数无循环、with、try/finally、except 场景 → 不适用。
- W13 finally return 丢值：无 finally → 不适用。
- W14 CFG 汇合点重建：W14-B 修的是**分支尾裸 return**；此处丢失的是**带常量值的嵌套 return True 且触发因子特定**；elif 扁平化/负极性 DeMorgan 形态也未出现 → 非 W14 主残留。例外见下述 R15-10。

### 判定：新家族 W15「链式比较（SWAP/COPY 指令序列）重建缺陷」

最小化探针（13 例，8 FAIL）将触发因子精确定位到 Python 3.11 链式比较特有的 `SWAP(2)/COPY(2)/COMPARE_OP/JUMP_IF_FALSE_OR_POP/SWAP/POP_TOP` 序列：

| 子形态 | 最小实例 | 字节码症状 |
|---|---|---|
| W15-A 中缀截断 | `r = sld <= self._engine.trading_dt <= ntd` | 中缀只剩首段 `LOAD_FAST self`，LOAD_ATTR 链剥离（58 vs 38 字节） |
| W15-A' 中缀灾难级损坏 | `r = o.get().v <= x.y <= z` | 方法调用中缀被替换为 `True` 字面量 + 后继 return 蒸发（94 vs 38 字节） |
| W15-B 吞并后继 return | `r = a<=b<=c` 换行 `return r` | `LOAD_FAST r; RETURN_VALUE` → `LOAD_CONST None`（二元/三元链均复现） |
| W15-C 真臂 return 值丢失 | `if lo<=p<=hi: return True`（有无尾部语句均触发；False 极性同样触发） | 真臂 `LOAD_CONST True/False` → `None`，源码重写为 `if: pass / else:` |
| W15-D while 条件注入 break | `while lo<=p<=hi: p = p-1` | 循环体前被插入虚假 `break`，真身变死代码，语义死循环（78 vs 40 字节） |
| W15-E 赋值蒸发悬空引用 | then 体 `w=calc(); r=v<=w; if r: return True` | `r = v <= w` 蒸发，嵌套 `if r` 变 LOAD_GLOBAL（运行时 NameError） |

控制组证明边界：简单条件真臂 return PASS；直接 `return a<=b<=c` PASS；`flag and a<=b<=c` 混合条件 PASS——**触发因子是链式比较本身在赋值/纯条件位置的重建，而非 return/if 结构**。

price_validator 四处缺陷与子形态对应：①=W15-E（then 体赋值蒸发）、②=W15-A、③=W15-C/E 组合（嵌套 if-return 在共享汇合点下蒸发）、④=W15-C（真臂值丢失+pass/else 重写）。

### 伴生发现（疑似 W14-B 门控边界残留，单列交修复工程师确认）

R15-10：then 体普通赋值 + 嵌套 if 消费变量 + 函数尾显式 `return None` 时，该显式 return None 不发射，重编译多出冗余汇合块（28 vs 32 字节）。W14-B 的发射门控要求"RETURN 之后仍有可达非平凡代码"，而此处 return None 是多前驱共享汇合块且其后无代码 → 门控误抑制。与 W15 触发路径独立（算术赋值即触发）。
