## Root Cause
### W21-A: IfRegion creation on finally normal-path copy blocks
**Defect family**: W21 — IfRegion incorrectly created for blocks already owned by TryExceptRegion as finally_copy_blocks (normal-path finally body copies).

**Root cause**: In `_identify_conditional_regions` (region_analyzer.py), the check at line ~13611 filtered out blocks containing `PUSH_EXC_INFO`/`CHECK_EXC_MATCH`/`RERAISE` (exception-path blocks), but did NOT filter out normal-path finally copy blocks. These blocks end with `POP_JUMP_FORWARD_IF_FALSE` (conditional jump), which triggers IfRegion creation. The IfRegion then generated the `if 'filedump' in locals(): filedump.close()` code a second time, producing duplicate `filedump.close()` calls in the output.

**Affected code**:
- `region_analyzer.py` `_identify_conditional_regions`: Missing guard for blocks in `TryExceptRegion.finally_copy_blocks`
- `region_ast_generator.py` `_generate_try`: Post-try block collection did not include `region.blocks` in `_known_struct`, allowing finally normal-path successor blocks (e.g., implicit return None, if-branch body) to be collected as post-try code and emitted as bare statements.
