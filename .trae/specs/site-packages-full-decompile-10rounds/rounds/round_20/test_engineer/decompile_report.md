## 1. 编译形态实验（判别式依据）

对 7 种循环/返回/跳出形态编译 3.11 字节码对比，确立关键事实：

| 形态 | 字节码 |
|---|---|
| for + break（出口为隐式 return None） | `[POP_TOP, LC None, RETURN_VALUE]` |
| for + return None | 同上——**字节码同形，歧义** |
| for + break（出口有实际代码，如 `return out`） | `[POP_TOP, JUMP_FORWARD→exit]` |
| while + return None / break | `[LC None, RET]` / `[JUMP_FORWARD]`（无 POP_TOP） |

结论：break↔return 可互换的字节码前提是「循环出口为隐式 return None」。
