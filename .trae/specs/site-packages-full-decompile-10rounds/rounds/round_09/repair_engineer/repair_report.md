## 3. 最终边界判定规则描述

**FOR_ITER 耗尽跳转目标 / while 条件假出口的循环节归属判定（`_find_loop_else`）：**

1. **break 证据优先**：循环体存在 break 边时，else 区间 = [for_iter_exit, break 目标最近公共后必经节点)，维持原算法不变——这是"确为 loop-else 且有回边证据"的唯一字节码可证形态。
2. **无 break 时以兄弟结构头判定归还**：出口候选块满足任一条即为「合并点之后兄弟结构」的头，不得计入循环节（blocks+else_blocks）：
   - 末条指令为前向条件跳转或短路跳转（If/BoolOp 条件结构头）；
   - 已被先归约的结构化区域（TryExcept/With/Match/Assert）登记为入口；
   - 含 FOR_ITER/GET_ANEXT（另一循环结构头）。
   普通顺序块仍由循环消费（保持存量行为）。判定实现于 `_is_post_merge_sibling_head`，对 for 与 while 两条路径统一生效。
3. **归还后的发射保障**：被归还块由其归属区域（尾随 IfRegion/TryExceptRegion 等）经父级顺序位置正常发射；`_collect_branch_blocks` 只沿正常控制流边展开，防止异常表隐式边把 handler/清理尾块吸进分支体。
4. 全部判据为 CFG 结构判据（指令形态 + 区域归属 + 异常表条目关系），以回边/支配关系为准，无 depth 硬编码、无 pyc 文件特判、无反模式前缀命名。
