## 4. 根因方向推断

**结论：新缺陷家族——「分支内循环 + 合并点后兄弟语句」的区域归属错误；不是 R07/R08 已修模式的残留变体。**

与已修模式逐一对照：

| 已修模式 | 是否命中 | 判据 |
|---|---|---|
| docstring 发射 | 否 | docstring 常量与发射均正确 |
| 嵌套 if/and 折叠目标一致性（R08 主因） | 否 | 本例无 BoolOp 链折叠痕迹 |
| except handler 吸收（R08b PUSH_EXC_INFO 补偿） | 否 | 两层 try 的 handler 边界与异常表完全正确 |
| with 前导赋值双份发射 | 否 | 本函数无 with |

### 实测机制证据（区域转储）

用 `RegionASTGenerator(cfg)` 对最小复现做区域级对照（对照组 = 同结构但分支内无循环）：

**丢弃形态（except handler 内，repro_01/02/10/12 = 目标 pyc 形态）**
```
blk@122: LOAD_GLOBAL n; ... POP_JUMP_FORWARD_IF_FALSE->178   ← 尾随 if 头部（下一兄弟语句）
LoopRegion blocks=[72,86,88,122]  orelse_blocks=[122]        ← 循环把 122 吞进 blocks+orelse！
尾随 IfRegion blocks=[122,144,172,178] merge_block=None      ← 且 merge 丢失，从未被发射
```
违反「每块唯一归属」（R08 已确立的原则 2）：FOR_ITER 耗尽目标块同时是循环 orelse 成员和后续 IfRegion 的 entry。

**伪 else 形态（普通函数尾 + raise，repro_03/08/09）**
```
LoopRegion blocks=[36,50,52,86]  orelse_blocks=[86]          ← 同样吞并尾随 if 头部 86
尾随 IfRegion 本身正确（blocks=[86,118] merge=146 无 else）
但发射产物为: if x.n == 0: y()  else: raise Err(err)         ← raise 被吸入伪 else，语义改变
```

**对照组证明触发条件**：同结构去掉分支内循环后区域结构完全一致且 PASS（repro_06/repro_11）。
即缺陷触发条件 = **if/else 分支内含循环 且 FOR_ITER 出口目标是合并点上的后续兄弟语句头部**。
