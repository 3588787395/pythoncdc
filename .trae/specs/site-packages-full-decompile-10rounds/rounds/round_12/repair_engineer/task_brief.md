## 1. 根因证据（偏移级）

源码语义：`except exception.IQInvalidArgument:` 被反编译为 `except exception:`。

### 1.2 根因链（三段）

1. **主嫌（截断点）**：`core/cfg/region_analyzer.py:8026-8043` `_extract_except_handler`
   ```python
   pre_check_instrs = []
   for instr in handler_entry.instructions:
       if instr.opname in _CHECK_OPS:      # CHECK_EXC_MATCH/CHECK_EG_MATCH
           break
       if instr.opname in ('LOAD_NAME', 'LOAD_GLOBAL'):
           pre_check_instrs.append(instr.argval)
   ```
   只收集两个加载操作码的 argval 字符串：`LOAD_GLOBAL exception; LOAD_ATTR IQInvalidArgument` → `['exception']` → exc_type='exception'；下标/调用/cell 变量根 → `[]` → exc_type=None。
   注意 3.11 中 `LOAD_ATTR` 的 arg 低 1 位是 method-call 标志（本例 argval='IQInvalidArgument' 无 method 位）。
2. **放大点**：`core/cfg/region_ast_generator.py:19101-19111`——str(exc_type) 直接包装为 `{'type':'Name','id':...}`；exc_type=None 时 handler_node 不设 exc_type 键。（该处已支持 dict 直通，可承接完整表达式节点。）
3. **退化终点**：`core/cfg/ast_converter.py:1405-1406`——exc_type None → type_node None → 发射裸 `except:`。裸 except 与"匹配失败继续向下分发"语义完全相反，且落在链中时直接 SyntaxError。

## 2. 嫌疑方法线索（按优先级）

1. `core/cfg/region_analyzer.py::_extract_except_handler`（L7957-8143）：pre-CHECK 区间表达式重建。建议做法：
   - 最小改动：在收集循环中同步跟踪 `LOAD_ATTR`（拼接 `.attr` 点链，注意剥离 arg&1 method 位）、`LOAD_FAST`/`LOAD_DEREF`（本地/cell 名）、`BINARY_SUBSCR`（生成 `expr[const]`），BUILD_TUPLE 分支保持既有逻辑但元素用完整点链；
   - 更彻底：复用项目内已有的通用"指令序列→表达式"归约器（ast_generator_v2/code_generator 中普通语句表达式已能正确还原 `exception.IQInvalidArgument`、`tbl[0]` 等，可对照其实现），产出完整表达式 dict 直通 `handler_node['exc_type']`；
   - **兜底红线**：任何无法识别的形态严禁落到 exc_type=None（裸 except）。保守回退应为输出 `Exception` 并留告警标记，或至少保证不产生 SyntaxError。
2. `core/cfg/region_ast_generator.py` L19101-19111 与 `_outer_handler` R08b 分支（L19212-19214）：确认 str 包装路径对点链字符串 `'exception.IQInvalidArgument'` 能原样发射（含点的字符串作为 Name id 输出前需验证 code_generator 不做二次处理，必要时改为 Attribute 节点 dict）。
3. 同构副本排查：`region_analyzer.py::_follow_except_chain`（≈L8145）与 structured_analyzer.py `_extract_exception_handler`（≈L13741，含首字母大写启发式 val[0].isupper()——小写模块名 `exception` 也会被该判据拒绝）存在同构逻辑；请确认实际生效调用路径只修主路即可，但勿遗漏被并行调用的分支。
4. 回归自检清单：禁止改动 R07-R11 已修逻辑（docstring 折叠、boolop 链尾豁免/handler 误吸收、循环兄弟块、with 兄弟表达式语句、finally 重排/孤立 NOP）。裸名 `except A:`、元组 `(A, B)`、as 绑定等现状 PASS 形态必须保持（见 repro_12 对照组）。
