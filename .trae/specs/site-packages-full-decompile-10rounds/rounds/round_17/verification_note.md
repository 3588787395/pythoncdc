## 根因与修复（W16-B 完成）

CPython 3.11 对首目标为属性/下标的链式赋值（`self.x = d[k] = []`）的实际布局是
`[值指令][COPY 1][对象装载][STORE_ATTR]` —— 对象装载位于 COPY 与 STORE **之间**，
而非 R16 初版假设的 `[对象][值][COPY]`。修复：
- 入口门控自 STORE 向前收集连续装载指令构成对象窗口（load-ish 后缀扫描），窗口左邻必须是 COPY 1；
- 窗口经 `_w16_split_value_groups` 分组：STORE_ATTR 要求恰 1 组、STORE_SUBSCR 要求恰 2 组（容器+键）；
- 值指令 = 窗口左边界之前的段，沿用终结符洁净校验。

另修复 R16 引入的动态链终止循环方向错误（首版把末目标排除在链外——正确语义是
「无 COPY 前导间隙的存储即末目标，包含之」），并新增链后兄弟语句直线残余通用重建
（`total = len(buf); return total` 不再丢失/错并）。
