# Round 68 · 采纳合同更正（ADR-1，2026-09-25）

## 背景：BRIEF §3 判据 3 写错了
BRIEF 给六个诊断代理的采纳合同判据 3 原文是：

> 名下靶支严格变好，且**缺陷量 Σ|orig−decomp| 净减少**（形状移动但 Σ|Δ| 不变 ⇒ 拒）

这条判据来自 R67 diag3 被回退的教训（那次「形状移动而 |Δ| 不变」确实是空转）。但它把
**唯一能证明纯次序修复有效的证据**也一并 veto 了：对已经 `orig_count == decomp_count` 的位移族，
任何正确的次序修复都**必然**保持 Σ|Δ| 恒定，于是按字面执行会杀掉所有正确候选。

diag2 在 `matcher::match` 上把这一点变成了实测事实（`diag2/FACTS.md`）：
- landed 已 `match 715/715`（长度完全对齐），缺陷形状是纯位移：
  `delete A[199:500] + delete A[622:626] → insert B[470:775]`，A=B=777，`hunks=10 first_diff=517`；
- 该文件的 Σ|Δ| 恒为 121，**与任何纯次序修复无关**。

而位移族恰恰是本项目当前排名第一的残余缺陷家族
（见 memory `project-r66-displacement-family-lead`：klinedata 5 支 + matcher，R64/R66/R67 三轮点名的同一机制）。
所以判据 3 的原文不是「保守」，而是**对本轮最有价值的一类修复系统性失明**。

## 更正后的判据 3（中心验证按此执行）
把「Σ|Δ| 净减少」拆成两条，按候选**名下缺陷的类型**分别适用；分类证据必须来自 Step 1 的
归一化 hunk 表，不允许候选方自称：

1. **缺失/过冲型**（`orig_count != decomp_count`，或严格尺 `seq_len`）：
   维持原判据——**Σ|Δ| 必须净减少**，且不得用「少发射语句」换取（R23 教训：还原被丢指令会抬高 Σ|Δ|，
   这一支只允许 veto「过度发射」这一步，restore-missing 用 MUST_CONTAIN + `first_diff` 回移来判）。
2. **纯位移/次序型**（`orig_count == decomp_count` 且严格尺已是 `seq_diff`/`target_diff`）：
   改为要求 **归一化 hunk 数严格下降（朝 0）且 `first_diff` 严格回移**，同时
   **Σ|Δ| 不得上升**（不升即可，不要求下降）+ **严格尺该 code object 不得新增 `target_diff`**
   （R42 教训：长度对齐的产物仍可能是假 ok，jump 目标必须逐条对得上）。

两条都仍然被更高的门夹着，任何一条不过即回退：
金丝雀 4 sha 逐字节不变 ∧ 45 项电池 worse-than-landed=0 ∧ 无 ERR ∧ 锚点 `count==1`
∧ 同层次结构判据 + 三要素注释 ∧ 自己的合成见证咬合。
