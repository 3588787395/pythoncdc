rcm-r08: fix Pattern T3 in graph.pyc (_generate_try post-try block detection)

Add block_to_region ownership guards to both branches (else_blocks +
try_blocks) of the post-try block detection in _generate_try, mirroring
the R07 Pattern T fix in _generate_with / _process_if_blocks.

Root cause: when a try-except is nested inside an outer try-except that
wraps a for/while-loop, the inner else_blocks/try_blocks successors
include the outer handler_entry via CFG exception edges. Without the
ownership guard, the inner _generate_try collected the outer
handler_entry (e.g. graph.pyc create_full_graph block 640) as a
post-try block and marked it generated. The outer _generate_try then
skipped the except handler (handler_entry in generated_blocks) -> try
without except -> SyntaxError.
