## 1. 三个目标单元：dis 级实差与闭合证据

### 1.1 `<module>.itn`（C-a：`elif <简单比较> and <链式比较>`）

dis（`c1_itn.pyc`，仅列条件链块）：

```
   0 LOAD_CONST 0 ; LOAD_FAST n ; SWAP 2 ; COPY 2 ; COMPARE_OP <= ; POP_JUMP_FORWARD_IF_FALSE ->42
  18 LOAD_CONST 8 ; ... ; BINARY_OP ** ; COMPARE_OP < ; POP_JUMP_FORWARD_IF_FALSE ->52
  40 JUMP_FORWARD ->46
  42 POP_TOP ; JUMP_FORWARD ->52            # 链式比较组「假边清理块」
  46 LOAD_CONST 1 ; STORE_FAST s ; JUMP_FORWARD ->158
  52 LOAD_FAST fmt ; LOAD_CONST 'GNU' ; COMPARE_OP == ; POP_JUMP_FORWARD_IF_FALSE ->128
  64 LOAD_CONST 256 ; ... ; SWAP 2 ; COPY 2 ; COMPARE_OP <= ; POP_JUMP_FORWARD_IF_FALSE ->118
  94 LOAD_CONST 256 ; ... ; COMPARE_OP < ; POP_JUMP_FORWARD_IF_FALSE ->128
 116 JUMP_FORWARD ->122
 118 POP_TOP ; JUMP_FORWARD ->128            # 组内清理块
 122 LOAD_CONST 2 ; STORE_FAST s ; JUMP_FORWARD ->158
 128 LOAD_GLOBAL ValueError ; ... ; RAISE_VARARGS 1
 158 LOAD_FAST s ; RETURN_VALUE
异常表：[]（无异常表，无循环）
```

- 修前：`BoolOp 链`在成员准入点被 `_is_nested_if_else_pattern` 判成「嵌套 if-else」——判据是
  `chain[0] 跳转目标偏移 > chain[1] 跳转目标偏移`（128 > 118），**但 chain[1] 的目标 118 是链式
  比较组的组内清理块（POP_TOP; JUMP_FORWARD->128），不是源级 else**。链被 pop 掉 ⇒ IfRegion
  层级重建成 `elif fmt=='GNU': if <半条比较>: ... else: raise`。
- 修后（`[v165-CCMEMBER]`）：链成员失败出口先经「纯跳转连接块」归一（`_v165_cond_exit_hops`：
  块内有效指令 ⊆ {POP_TOP, JUMP_FORWARD/JUMP_ABSOLUTE} 且唯一后继，最多 4 跳，环上即停），
  128 == 128 ⇒ 判据不命中。探针实测：`BoolOpRegion(52) op_chain=[(52,'and'),(64,'and')]
  merge_block=118`，条件块保持 52（BoolOp 入口），elif 臂分派点取组内**末比较块** 94，
  臂体=122（穿透连接块 116），臂 else=128，链出口=158；生成侧再豁免「elif 臂块被标记已生成」。
- 判官：`c1_itn.pyc` 1/2 → **2/2 Equal**；tarfile `<module>.itn` Failure → **Equal**。

### 1.2 `TarInfo.create_pax_header`（C-b：`if not <链式比较>:` 作链头 + elif）

dis（真模块 tarfile.pyc，块内要点）：

```
 438 STORE_FAST val_int ; LOAD_CONST 0 ; LOAD_FAST val_int ; SWAP 2 ; COPY 2 ;
     COMPARE_OP <= ; POP_JUMP_FORWARD_IF_FALSE ->480
 456 ... COMPARE_OP < ; POP_JUMP_FORWARD_IF_TRUE ->498      # if-not 末段极性
 478 JUMP_FORWARD ->482
 480 POP_TOP                                                # 组内清理块
 482 ... JUMP_FORWARD ->516                                 # then 体尾（跳过整条链）
 498 LOAD_FAST val_is_float ; POP_JUMP_FORWARD_IF_FALSE ->516   # <= elif 链头
 502 ... STORE_SUBSCR ; STORE_FAST needs_pax ; (落到 516)
 516 LOAD_FAST needs_pax ; POP_JUMP_FORWARD_IF_FALSE ->564  # 链后兄弟 if
```

- 修前：链式比较区域只覆盖 [438,456,478,480,482]，`merge_block=498` 被当成「链后语句」，
  498 因 `block_to_region[438]` 之类守卫被跳过 ⇒ 产物 `if not 0<=val_int<8**(digits-1): ...`
  之后紧接**独立** `if val_is_float:`（少 1 条把两臂分开的 JUMP_FORWARD）。
- 修后（`[v165-CCHEAD]`）：`_v165_cc_head_else_chain` 判据 = else 候选块（否定形取 `merge_block`，
  非否定形取 `else_blocks` 首块）①以正向条件跳转结尾 ②其全部前驱都在链区域内或就是它自己；
  命中即用既有 `_build_elif_region` 重建整条 if/elif/else 并**就地升级**原链区域（同一对象改
  `region_type/blocks/merge_block/then_blocks/else_blocks/elif_*`，不新增同入口第二区），
  链式比较字段原样移植。探针命中：`block=438 cands=[498,480] else_head=498 outer_exit=516
  new=IfRegion`。产物：`elif val_is_float:` 复原，判官 Equal。
- 附带修：`[v165-SBDOWN]` —— 链尾合并块（516）本身是下游语句区域入口时，豁免 shared-block
  双角色（否则 `_check_elif_chain` 在 `_sb_downstream_if is None` 处 return None，整条 elif 弃权）。

### 1.3 `TarFile.gettarinfo`（C-c：`not <属性加载> and A and B and C`）

dis（`c3b_notand_attr.pyc`）：

```
   0 ... LOAD_ATTR ino ; ... BUILD_TUPLE 2 ; STORE_FAST inode ;
     LOAD_FAST self ; LOAD_ATTR deref ; POP_JUMP_FORWARD_IF_TRUE ->150
  44 LOAD_ATTR nlink ; LOAD_CONST 1 ; COMPARE_OP > ; POP_JUMP_FORWARD_IF_FALSE ->150
  66 LOAD_FAST inode ; LOAD_ATTR inodes ; CONTAINS_OP 0 ; POP_JUMP_FORWARD_IF_FALSE ->150
  84 LOAD_FAST arcname ; ... COMPARE_OP != ; POP_JUMP_FORWARD_IF_FALSE ->150
 118 ... t='LNK' ... JUMP_FORWARD ->190
 150 ... t='REG' ... POP_JUMP_FORWARD_IF_FALSE ->190
 170 ... STORE_SUBSCR ; 190 return t
```

- 修前：链首块前缀里有 `inode = (st.ino, st.dev)`（STORE_FAST），后续成员读 `inode`，
  被 R14b 前缀消费门 `_create_boolop_region_from_chain` L33789 直接 `return None` ⇒ 链不建区，
  IfRegion 退化成 `if not self.deref: if A and B and C: … else: …`（else 挂内层）。
- 修后（`[v165-ATTRPREFIX]`）：门收窄为「前缀里含 CALL（带副作用的调用语句）才拒绝」——纯值前缀
  （无 CALL）不构成独立语句，赋值照常由入口前缀发射、条件可入链。判据只读前缀指令 opcode 集。
  探针：`_detect_boolop_conditional_chain(0)` 返回 4 成员链 `[(0,'and'),(44,'and'),(66,'and'),(84,'and')]`，
  `_create_boolop_region_from_chain` 由 None → `BoolOpRegion(entry=44…entry=0)`。
- 判官：`c3b_notand_attr.pyc` 2/3 → **3/3 Equal**；tarfile `TarFile.gettarinfo` Failure → **Equal**。
